# Terminal OS - Pardus 25 XFCE Toolbox

Samsung SyncMaster'da test edildi, Pi 4'te de çalışır.

Videodaki gibi mavi menülü Python 3.1 Toolbox.

## Kurulum
chmod +x minios.sh arac.py
./minios.sh

## Özellikler
- Sistem bilgisi
- Çekirdek optimize
- Disk, RAM, CPU testleri
- 495MB sıkıştırılmış MATE seçeneği

Not: Sadece Linux'ta çalışır, Python 3 gerekli.
