# Terminal OS - Pardus 25 XFCE Toolbox

Python altyapısı ile geliştirilmiş, tamamen terminal tabanlı bir Linux sistem yardımcısıdır.

Samsung SyncMaster 713n ve Raspberry Pi 4 üzerinde test edilmiştir.

Videodaki gibi mavi menülü, Whiptail/Dialog tabanlı arayüz.

### 🚀 Yakında: ISO Sürümü Geliyor!
Şu an toolbox olarak çalışan bu proje, yakında tam bağımsız bir ISO dosyası olarak yayınlanacak. Kendi çekirdeği ve 495MB sıkıştırılmış MATE masaüstü ile gelecek.

## 💻 Uyumluluk
- **Linux:** Pardus 25 XFCE (Ana sistem), Debian tabanlı tüm dağıtımlar
- **Raspberry Pi:** Pi 4 / Pi 5 (2GB RAM ve üzeri önerilir)
- **Gereksinimler:** Python 3.1+, Linux terminal

## ⚙️ Kurulum
Dosyaları ana dizine atın ve terminalden şu komutları çalıştırın:

```bash
chmod +x minios.sh arac.py
./minios.sh
